Validation Today

    Right now your code probably looks like this:
    if age is None:
        ...
    elif not isinstance(age, int):
        ...
    elif age < 0:
        ...
    That's procedural programming.

Validation with Marshmallow

    age = Integer(
        required=True,
        validate=Range(min=0)
    )

    That's declarative programming.

Marshmallow returns a Python dictionary.
This separation of responsibilities is important:
- Marshmallow: Python objects ↔ Python dictionaries.
- Flask: Python dictionaries → JSON over HTTP.

If validation fails, ValidationError is raised.


load()
- Used for incoming data.
- Validates.
- Deserializes.
- Returns validated Python data.
- Raises ValidationError if invalid.

dump()
- Used for outgoing data.
- Serializes Python objects.
- Returns Python dictionaries.
- Flask's jsonify() turns those dictionaries into JSON.
